# @hinote/mermaid

`<Mermaid>` for [hinote](https://github.com/halqme/hinote/tree/main/packages/hinote): a [Mermaid](https://mermaid.js.org) diagram drawn as SVG by [beautiful-mermaid](https://github.com/lukilabs/beautiful-mermaid) while the slide renders, in the deck's colors and fonts, so the page gets a finished picture and loads no script for it.

Its guide ships with hinote, so an agent can read it before the package is installed: `hinote skills get mermaid`.
