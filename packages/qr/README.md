# @hinote/qr

`<Qr>` for [hinote](https://github.com/halqme/hinote/tree/main/packages/hinote): a QR code, such as the link to the slides at the end of a talk, drawn as inline SVG while the slide renders, so the page loads no script or image for it.

Its guide ships with hinote, so an agent can read it before the package is installed: `hinote skills get qr`.
