# Slidev・Marp との比較

[English](comparison.md)

同じ5枚のスライドを hinote、[Slidev](https://sli.dev)、[Marp CLI](https://github.com/marp-team/marp-cli) で作り、インストール、起動、書き出しを測りました。5枚の中身は、タイトル、1つずつ出す箇条書き、TypeScript のコード、本文、締めです。元のファイルは [`bench/`](../bench) にあります。

## 結果

2026-11-17 に測りました。

|                                                  |    hinote 0.1.0 |     Slidev 53.1.0 |   Marp CLI 4.5.1 |
| ------------------------------------------------ | --------------: | ----------------: | ---------------: |
| インストールするパッケージ数                     |           **3** |               639 |              155 |
| `node_modules` の大きさ                          |      **5.4 MB** |            570 MB |           131 MB |
| インストールにかかった時間                       |      **0.7 秒** |             12 秒 |           3.3 秒 |
| 開発サーバーが応答するまで                       |     **0.07 秒** |           0.59 秒 |          0.37 秒 |
| 開発サーバーの起動から、ブラウザに表示されるまで |     **0.17 秒** |           1.57 秒 |          0.63 秒 |
| 書き出しにかかった時間                           |     **0.04 秒** |           1.59 秒 |          0.22 秒 |
| 書き出したもの                                   | 1ファイル 17 KB | 45ファイル 791 KB | 1ファイル 108 KB |
| 書き出したもの（gzip）                           |            6 KB |            329 KB |            24 KB |

- 環境は Apple M4 Pro、メモリ 48 GB、macOS 27.2.1、Bun 1.4.4、Node.js 26.13.1 です。
- 開発サーバーの2行と書き出しの時間は、何回か測った中央値です。開発サーバーは、初回を除いた3回を測りました。書き出しは、1回準備のために動かしたあとの5回を測りました。
- 初回の起動も、ほぼ同じでした（hinote 0.14 秒、Slidev 1.63 秒、Marp 0.67 秒）。Slidev の初回は、Vite のキャッシュを消してから測っています。

## 測り方

```bash
bun bench/run.ts            # インストール、書き出し、開発サーバーの応答まで
bun bench/run.ts --browser  # ブラウザに表示されるまでも測る（agent-browser が必要）
```

- **パッケージ管理:** 3つとも Bun でインストールしました。
- **インストール:** キャッシュを空にして測ったので、ダウンロードの時間を含みます。ネットワーク次第で変わるので、目安として見てください。
- **ブラウザに表示されるまで:** 開発サーバーを起動してから、headless Chrome にタイトルの文字が出るまでの時間です。ブラウザを操作する分の時間（0.1 秒ほど）も入っています。
- **書き出し:** `hinote build`、`slidev build`、`marp slides.md -o dist/index.html` です。

## 数字を読むときの注意

書き出したものは、中身がそろっていません。

- **hinote:** 視聴画面だけの HTML です。発表者画面と同期は入りません。
- **Slidev:** Vue で動く静的サイト（SPA）で、発表者画面などの機能も入ります。
- **Marp:** 1ファイルの HTML で、発表者画面も入ります。

軽さは、機能を絞った結果でもあります。上の数字は、そのつもりで見てください。

## 機能の違い

|                      | hinote                                                                     | Slidev                                                             | Marp CLI                                                                 |
| -------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| 書き方               | TSX（Hono/JSX）                                                            | Markdown と Vue コンポーネント                                     | Markdown と CSS テーマ                                                   |
| 動かす環境           | Bun                                                                        | Node.js 22.22 以上                                                 | Node.js 18 以上                                                          |
| 部品を作る           | JSX のコンポーネント。async にもできる                                     | Vue コンポーネント                                                 | なし（CSS で見た目を変える）                                             |
| 発表者画面           | サーバーで出すときだけ                                                     | あり。スマートフォンから操作もできる                               | 書き出した HTML にもある                                                 |
| 書き出し             | 視聴画面だけの HTML 1ファイル。PDF はブラウザの印刷で作る                  | 静的サイト。PDF・PNG・PPTX には `playwright-chromium` を別に入れる | HTML 1ファイル。PDF・PPTX・画像には Chrome・Edge・Firefox のどれかが要る |
| サーバーとして動かす | デッキが Hono アプリなので、`bun deck.tsx` や `app.route()` でそのまま動く | 開発サーバー                                                       | `-s` でディレクトリを配信する                                            |

Slidev は、hinote にない機能をたくさん持っています。描き込み、録画、LaTeX、Mermaid の図、アイコン、テーマの共有、エディタとの連携などです。Marp は、Markdown だけで書けて、PowerPoint にも書き出せます。

hinote が向いているのは、次のような場合です。

- 依存を小さく保ちたい。
- 書き出したファイルを軽くしたい。
- スライドを TypeScript のコードとして書き、データを読んで描画したい。
- 作ったデッキを Hono アプリとして、別のアプリに組み込みたい。
