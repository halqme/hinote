# hinote

Write slides with Hono and Hono/JSX.

The package and its guide are in [`packages/hinote`](packages/hinote/README.md). To work on hinote, see [Developing hinote](CONTRIBUTING.md).

| Package                           | What it is                                               |
| --------------------------------- | -------------------------------------------------------- |
| [`hinote`](packages/hinote)       | The CLI and the core components.                         |
| [`@hinote/code`](packages/code)   | `<Code>`, syntax highlighting with `@pierre/highlights`. |
| [`@hinote/types`](packages/types) | Types shared by `hinote` and the `@hinote/*` packages.   |
